# Fonts

Put the licensed display fonts here with exactly these file names:

| Font            | File name                                        | Used for                  |
| --------------- | ------------------------------------------------ | ------------------------- |
| Botch (hvnter)  | `Botch.woff2` (or `Botch.otf`)                   | Name and headings         |
| Oneheart Script | `OneheartScript.woff2` (or `OneheartScript.otf`) | Tagline and short accents |

Saira comes from npm (`@fontsource-variable/saira`), so nothing to add for it.

`.woff2` is preferred because it is much smaller. You can convert an `.otf`/`.ttf`
with any font converter (for example https://cloudconvert.com/otf-to-woff2).
Check that each font's license allows web embedding.
